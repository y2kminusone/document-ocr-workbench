# 공개본 범위

## 원본 구현에서 선별한 부분

- API, 문서 분류, 영역 탐지, OCR 서비스 및 핵심 처리 모듈.
- PDF 페이지 작업 관리, 재처리, 상태 관리, 결과 저장·변경 이력.
- 분류와 결과 검토·표 편집을 위한 브라우저 UI.

원본 구현의 일반적인 문서 처리 흐름을 보존했습니다. 기존 Git 이력이나 전체 운영 시스템을 복제한 저장소는 아닙니다.

## 공개본 작성 과정에서 변경한 부분

- 회사 접속 주소, 자격 증명, DB 이름, 모델 경로를 환경 변수와 로컬 예제로 대체.
- 서버 기본 바인딩을 localhost로 제한.
- 모델 파일을 사용자 홈 등에서 재귀 검색하는 코드를 제거하고 명시적 경로 사용.
- 실행에 쓰이지 않는 긴 주석 백업, 체크포인트, UI 백업 파일을 제외.
- README·개발 메모·의존성 목록·환경 설정 예제를 새로 작성.
- 실제 셀 변경 비교 함수를 사용하는 합성 예제와 회귀 테스트를 추가.

## 제외한 자료

원본 PDF·이미지, OCR 결과, 고객·업무 데이터, DB 덤프, 운영 로그, 모델 가중치, 실제 환경 변수·DB 연결 설정, 내부 운영 문서, 노트북 출력, 압축 파일, IDE 설정, Python 캐시, 기존 Git 이력.

## 검증의 경계

Python 문법 검사와 합성 데이터 기반 수정 이력 테스트는 공개본의 일부 동작을 검증합니다. 전체 OCR 추론·실제 DB 통합·브라우저 조작 및 성능을 검증한 결과는 아닙니다. 보존된 기술 기록만으로 작성자의 개인 기여율이나 측정 성과를 단정하지 않습니다.
